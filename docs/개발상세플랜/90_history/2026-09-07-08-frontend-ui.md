# 프론트엔드·UI 변경 이력 (2026-09-07 ~ 2026-09-08)

루트 README의 변경 기록에서 옮긴 문서입니다. WU-F5 발언 대기열·동기화 fragment,
투표·타임라인 화면, 색상 대비 수정과 UI·UX 플레이테스트 후속을 다룹니다.

## 투표 화면 대비와 후보 카드

투표 화면은 공개 snapshot의 생존자 목록을 표시하고, 서버가 허용한 후보만 선택할
수 있습니다. 후보 카드는 짙은 글씨와 보라색 선택 테두리로 구분하며, 결과 요약의
숫자·결정 단계·확인 안내는 밝은 카드 위에서 읽을 수 있도록 대비를 고정합니다.

## 자동 동기화·발언 대기열 (WU-F5)

게임 화면의 자동 동기화·공개 타임라인·AI 진행·발언 분석은 입력과 분리된
Streamlit fragment에서 갱신합니다. 2초 동기화와 1초 countdown이 채팅 입력을
다시 생성하지 않으며, 같은 자유 토론의 AI 발언으로 예약 window가 바뀌어도 초안과
포커스를 유지합니다. 실제 단계·행동 허용·생존 상태가 바뀌면 검증한 최신 snapshot으로
화면을 전환하며, 이 전환 직후에는 중복 GET을 하지 않습니다. 자동 조회 실패 시 기존
상태를 유지하고 연결 상태를 안내합니다.
자유 토론에서 Enter로 입력한 발언은 Front 세션의 FIFO 대기열에 예약됩니다.
전송을 기다리는 동안에도 다음 발언을 입력할 수 있고 예약 내용과 순서를 표시합니다.
한 건씩 최신 상태를 조회해 제출하며, 동일 사용자·게임·생존자·토론 단계·회차·마감
안에서 AI 진행과 버전/창이 충돌하면 자동 재시도합니다. 최근 1분 7회 제한에 걸리면
순서를 유지한 채 기다립니다. 응답이 불명확하면 최초 본문과 멱등 키로만 확인하여
중복 발언을 방지합니다. 서버의 마감·권한·버전 검증은 그대로 적용됩니다.
토론 종료·저장·이탈·사용자 변경 시 미전송 예약은 취소되며 다른 토론으로 넘기지
않습니다. 예약은 현재 Front 세션에만 있고 새로고침·재접속 후 영구 복원하지 않습니다.
이미 서버에 전송한 요청은 이탈로 취소되지 않을 수 있습니다.
제출 중에도 동기화 표시의 자리를 유지해 이전 타임라인이 회색으로 겹쳐 남거나
입력창 위치가 밀리지 않도록 합니다.
Shift+Enter의 줄바꿈은 전송할 때 공백으로 정리합니다. 입력 형식 검증 실패는 같은
토론 구간에서 오류와 원문을 보존해 수정할 수 있게 합니다. 투표·밤 행동·PASS는
기존 단일 요청과 재확인 방식을 유지합니다.
다른 플레이어 차례에는 본인의 제출 완료 대신 현재 발언자를 안내합니다.
이 복구는 Front 동기화 범위이며 Backend AI 작업 자체의 정지를 해결하지는 않습니다.

2026-09-08 WU-F5 자동 검증 명령은
`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest frontend_user/tests -o addopts='' -q`이며,
결과는 568개 통과·7개 실패입니다. 실패는
기존 HEAD에서도 재현한 F4 경고·최종 지목 문구 2개, F1 식별자 제어 3개, F6 결과
화면 새 게임 버튼 2개이며 이번 범위에서 수정하지 않았습니다. 발언 대기열 핵심
테스트 24개와 입력·동기화 테스트 119개가 통과했습니다. 전송 지연 중 연속 예약,
버전/창 충돌 자동 재시도, 응답 유실의 동일 키 확인, 빈도 제한 대기, 단계·사용자·저장
경계 취소와 늦은 응답의 상태 역행 방지를 검증했습니다. 자동 테스트는 합성 데이터와 mock을 사용했고,
이번 대기열 작업에서는 Backend·MCP 실행 코드를 변경하지 않아 해당 전체 회귀는 생략했습니다.
Chrome 실제 6인 게임에서 9개 발언을 빠르게 연속 예약한 뒤, 7회 제한 중 추가한
줄바꿈 발언까지 총 10개가 입력 순서대로 한 번씩 전송되는 것을 확인했습니다.
제한 중 8·9번 예약은 유지됐고 제한 해제 뒤 자동 전송됐습니다. 세 번의 20초 관찰,
총 5,745회 DOM 확인에서 초안 손실·비활성화·포커스 이탈·입력 영역의 로딩 흐림과
타임라인 중복은 0회였습니다. 최종 검증 게임은 저장하고 나갔습니다.
실제 한국어 IME 조합 이벤트는 별도로 검증하지 않았습니다.
개발 중 하위 Python 모듈 변경이 브라우저 새로고침 후에도 반영되지 않으면 실행
터미널에서 Ctrl+C 후 `./run_openai.sh`를 다시 실행하세요. 이번 브라우저 최종 검증은
개발 서버를 재시작해 최신 모듈이 반영된 상태에서 수행했습니다.

## AI 판단과 실행 표시

게임 화면의 **AI 판단과 실행**에서 정보 확인 → 판단 → 선택 → 적용 순서와 공개
판단 근거(공개 단서·진술 비교·확인 질문·근거 부족·추가 의견 없음)를 확인할 수 있습니다.
근거는 모델이 선택한 제한된 유형의 요약이며 실제 사고 원문이나 사실 검증 결과가 아닙니다.
모델의 자발적 PASS, 더미 고정 행동, 장애로 인한 규칙 대체를 구분하고, 적용 완료 후에도
미완성 응답·인증·요청 제한·모델 접근·MCP 조회/제출 오류를 그대로 표시합니다.
밤과 투표에는 기존처럼 개별 actor·역할·대상·응답 여부를 공개하지 않습니다.

## 결과·기록 화면 색상 대비

종료 후 **▣ 게임 기록 보기**의 밤·투표 기록에는 밝은 회청색 카드와 짙은 글자색을
함께 지정했습니다. 결과 요약 숫자와 보조 설명도 다크 테마에 영향을 받지 않도록
색상을 지정해 밝은 카드에서 읽을 수 있게 했습니다.
처형 투표·재투표·최종 지목의 행동 패널도 제목, 안내, 잔여 시간, 공개 요약과
후보 이름·생존 표기를 검은색으로 지정해 흰 배경에서 읽을 수 있게 했습니다.
이 색상 수정은 자동 테스트 없이 합성 투표 화면을 Chromium 다크 테마로 열어
제목·안내·후보의 검은 글자와 선택 후 제출 버튼의 대비를 확인했습니다.

## 타임라인·채팅 UI

게임·관전 공개 타임라인은 노란색 발언 말풍선과 행동 알림을 구분합니다. `AI 판단과 실행`은 기본적으로 접혀 있으며 펼쳐서 확인합니다. 종료 결과에는 마피아 선택과 최종 공격 대상을 구분하고, 두 선택이 갈린 경우 RNG로 결정되었다고 안내합니다. 비공개 선택은 게임 종료 후에만 표시합니다.

새 토론은 1분 45초 자유 채팅이며 플레이어별 최근 1분에 최대 7회 발언할 수 있습니다. 인간은 AI 처리 순서와 무관하게 발언하고, 발언해도 마감 시간이 연장되지 않습니다. 마감 시 첫날은 밤, 이후 낮은 투표, 최종 토론은 최종 지목으로 넘어갑니다. 저장·재개 시 남은 시간을 보존합니다.

발언 입력 중 다른 플레이어의 메시지가 도착해도 작성 중인 내용은 유지됩니다. Enter로
발언을 전송하고 Shift+Enter로 줄바꿈을 입력할 수 있으며, 화면의 전송 버튼도 사용할 수
있습니다.

자유 토론 검증: 실제 PostgreSQL에서 7회 상한·동시 제출·idempotency·AI 반복 발언·저장/재개·일반/최종 마감을 확인했습니다. 관련 API·Front 입력·Backend↔MCP 통합 테스트 67개 통과. 전체 회귀에서 남은 fixture·계층 경계 실패 14개는 기존 HEAD에서도 동일하게 재현됩니다. 유료 모델 호출은 검증에 사용하지 않았습니다.

AI 발언은 반말을 허용한 짧은 게임 채팅 구어체를 사용하도록 지시합니다. 보고서식 검증·신뢰도 표현과 매번 반복하는 상황 요약은 줄이고, 캐릭터별 어조와 승리 우선 판단은 유지합니다.

게임·관전 채팅 목록은 높이 480px의 독립 스크롤 영역입니다. 새 발언·행동 알림이 추가되면 Streamlit 기본 자동 스크롤로 채팅 최하단을 표시합니다.
